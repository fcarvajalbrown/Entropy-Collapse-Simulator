# Manuscript

The authoritative manuscript is the Word file **`Carvajal_RDLC_manuscript.docx`**,
formatted to the Revista de la Construccion (RDLC) template. It is generated by
`build_docx.py`, which computes every reported number at build time from the
analysis modules and the validation harness, so the paper cannot drift out of
sync with the code.

## Rebuild

```bash
pip install python-docx                 # only needed for the .docx build
python manuscript/generate_figures.py   # regenerate figures from live runs
python manuscript/build_docx.py         # write Carvajal_RDLC_manuscript.docx
```

## Contents

- Title, authors, highlights, abstract, keywords
- Introduction (with prior-art positioning: redundancy matrix, information-
  theoretic robustness, entropy-of-flow, strain-energy importance)
- Materials and methods (entropy, alternate load path, R_S, four criteria,
  implementation and three-tier verification)
- Experimental results and analysis (robustness index; R_S vs degree of static
  indeterminacy; entropy criticality vs compliance importance; criteria
  comparison; limitations)
- Conclusions and comments; back matter; references

Figures are in `figures/`. A plain-text reading copy is not maintained here to
avoid a second, diverging version; read the `.docx` or the source in
`build_docx.py`.
